# FindIt – CSE-E Lost & Found

## Run in VS Code
1. Open VS Code → File → Open Folder → select this `findit` folder.
2. Install the **Live Server** extension (Ritwick Dey).
3. Right-click `index.html` → **Open with Live Server**.

## Files
- `index.html` – page layout (notification board on top, login below)
- `style.css`  – design
- `app.js`     – login, Upload Item, Search Item, claim and confirm logic
- `roster.js`  – CSE-E Registration No. + names (edit this to fix or add students)

## Note
Data is stored in the browser (localStorage), so uploads are not shared between different phones/laptops yet.
Next step: Spring Boot + MySQL backend to share data across all students.
